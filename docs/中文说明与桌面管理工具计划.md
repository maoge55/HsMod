# HsMod 中文说明与 Windows 桌面管理工具计划

> 本文基于当前仓库源码整理，时间为 2026-07-09。文档重点说明当前 64 位 BepInEx 版本 HsMod 的项目结构、运行流程、Web 管理系统、配置项和后续 Windows 桌面管理工具规划。本次仅产出计划，不实现桌面工具。

## 1. 项目定位

HsMod 是一个基于 BepInEx 5 与 Harmony 的炉石传说插件，当前插件版本为 `11.3.0.2`，插件入口为 `HsMod.Plugin`，插件标识为 `HsMod`。

当前炉石客户端已于 2026-07-01 更新为 64 位程序，因此 Windows 安装侧应使用 `BepInEx_x64`。项目文件仍以 .NET Framework 4.8 类库形式编译，依赖 BepInEx、Harmony、UnityEngine 以及炉石客户端自身程序集。

项目能力大致分为以下几类：

- 插件全局开关、语言、配置模板、快捷键、变速齿轮、FPS 显示与帧率设置。
- 游戏体验优化：屏蔽弹窗、屏蔽游戏内消息、跳过结算提示、自动开结算盒、错误退出、移除焦点限制、移除窗口尺寸限制。
- 开包与收藏：快速开包、自动开包、全额分解、新卡标记清理、收藏卡牌数量显示、右键复制卡牌或外观 ID。
- 对局与好友：显示对手完整战网名、显示天梯等级、卡牌追踪、已知卡牌揭示、观战时显示双方手牌、复制对手 BattleTag、自动举报。
- 表情与快捷键：自动沉默、限制接收表情、思考表情控制、表情无冷却、表情快捷键、静音快捷键、模拟断线。
- 酒馆与佣兵：酒馆鲍勃静音、酒馆礼遇/收藏本地解锁、酒馆镀金、佣兵奖励自动领取、佣兵缩放、佣兵皮肤替换。
- 外观与皮肤：幸运币、卡背、棋盘、酒馆棋盘、击杀特效、鲍勃、英雄、宠物、卡牌最高特效、金卡/钻石/异画等显示规则。
- 模拟与开发功能：设备模拟、模拟开包、冒险购买、卡拉赞修复、Web 管理系统、WebShell、日志页面。

重要风险：

- 插件会 Patch 游戏进程与部分反作弊相关调用，存在账号安全与客户端稳定性风险。
- 默认 Web 服务使用 `http://+:端口/` 监听，可能暴露到本机所有网卡。若在云主机、局域网或公网环境运行，必须额外关注防火墙与端口暴露。
- WebShell 默认关闭，且不能通过当前 Web 配置接口直接开启；如手动开启，会允许通过 HTTP 执行系统命令，风险极高。
- 多数功能依赖炉石内部类型与 IL 结构，炉石版本更新后可能失效或导致 Patch 失败。

## 3. 编译与安装

### 3.1 编译

项目目标框架是 .NET Framework 4.8，README 中建议使用 .NET SDK 8.x 执行构建：

```powershell
dotnet build --configuration Release --no-restore
```

Release 输出默认位于：

```text
HsMod/Release/HsMod.dll
```

注意：

- `HsMod.csproj` 中配置了 `PostBuildEvent`，会执行 `HsMod/install.bat`。该脚本通常用于把编译出的 DLL 复制到默认炉石目录。
- 编译引用大量炉石客户端 DLL，若炉石更新导致引用缺失或签名变化，需要更新 `HsMod/LibHearthstone`。
- `GetHsLib.py` 是更新炉石运行库引用的辅助脚本。

### 3.2 Windows 安装

1. 下载或编译得到 `HsMod.dll`。
2. 下载 `BepInEx_x64`，解压到炉石根目录 `Hearthstone\`。
3. 创建目录：

```text
Hearthstone\BepInEx\unstripped_corlib\
```

4. 将项目 `HsMod/UnstrippedCorlib` 下的 DLL 复制到该目录。
5. 修改 `Hearthstone\doorstop_config.ini`：

旧格式：

```ini
dllSearchPathOverride=BepInEx\unstripped_corlib
```

BepInEx 5.4.23.2 及以上常见格式：

```ini
dll_search_path_override = BepInEx\unstripped_corlib
```

6. 将 `HsMod.dll` 放入：

```text
Hearthstone\BepInEx\plugins\
```

7. 启动炉石。

注意：

- 炉石安装路径不建议包含中文字符。
- 请使用 BepInEx 5；BepInEx 6 目前不作为适配目标。
- 插件可能与修改 `Assembly-CSharp.dll` 的方案或其他 BepInEx 插件冲突。

## 4. 启动流程

插件入口在 `Main.cs` 的 `Plugin : BaseUnityPlugin`。

### 4.1 Awake 阶段

启动时主要执行以下操作：

1. 调用 `Utils.EnhanceBepInExSetting()`，开启 BepInEx 与 Unity 日志落盘，关闭追加写入，隐藏 Manager GameObject。
2. 清理炉石缓存目录：

```text
Hearthstone Util ExternalDataPath/Cache
Hearthstone Util PersistentDataPath/Cache
```

3. 解析命令行参数。
4. 根据是否提供 `hsunitid` 决定配置文件路径：

```text
BepInEx/config/HsMod.cfg
BepInEx/config/<hsunitid>/HsMod.cfg
```

5. 执行 `PluginConfig.ConfigBind()` 绑定所有配置项。
6. 读取命令行覆盖项，例如端口、分辨率、对局日志路径、挂机模板。
7. 如果 `isPluginEnable=true`，绑定 Patch 配置委托并执行 `PatchManager.PatchAll()`；否则停止初始化。

### 4.2 Start 阶段

`Start()` 阶段主要执行：

- 创建并初始化 FPS 显示组件。
- 按 `targetFrameRate` 修改目标帧率。
- 如命令行指定 `width` 与 `height`，调用 `Screen.SetResolution(width, height, false)`。
- 如果网页背景为空或使用 `safeimg`，尝试获取安全背景图。
- 启动内置 Web 服务：`WebServer.Start()`。

### 4.3 Update 阶段

每帧主要处理：

- `autoQuitTimer` 到期后的强制退出逻辑。
- `F4` 固定功能：
  - 统计当前 Patch 数量并显示状态。
  - 重新加载 `HsSkins.cfg`。
  - 刷新语言状态。
  - 更新 `InactivePlayerKicker`。
  - 重启 Web 服务。
- 插件快捷键：
  - 齿轮倍率增减、归零、最大化。
  - 模拟断线。
  - 显示/隐藏 FPS。
  - 静音/恢复声音。
  - 一键分解全额反尘卡。
  - 清除新卡标记。
  - 投降、替换卡确认/结束回合。
  - 复制 BattleTag。
  - 沉默对手。
  - 表情快捷键。

## 5. 命令行参数

当前命令行参数由 `UtilsArgu` 解析，支持 `--key value`、`--key=value`、`/key:value` 等形式。

| 参数 | 作用 |
| --- | --- |
| `hsunitid` | 指定独立配置目录，适合多实例或多账号区分配置。 |
| `port` | 覆盖 Web 服务端口，必须在 `1-65535`。 |
| `width` | 指定窗口宽度。需与 `height` 同时使用。 |
| `height` | 指定窗口高度。需与 `width` 同时使用。 |
| `matchPath` | 覆盖对局日志路径。 |
| `afk` | 一键设置插件运行模板。 |

`afk` 取值：

| 值 | 行为 |
| --- | --- |
| `0` | 禁用插件并禁用齿轮。 |
| `1` | 启用插件、启用齿轮、应用挂机模板 `AwayFromKeyboard`。 |
| `2` | 启用插件、应用反挂机模板 `AntiAwayFromKeyboard`，但关闭快捷键。 |
| `3` | 启用插件，但禁用齿轮。 |
| `4` | 启用插件并应用反挂机模板 `AntiAwayFromKeyboard`。 |

插件还支持通过命令行传入 `VerifyWebCredentials` token 来绕过 Battle.net 启动。Patch 会在炉石读取 `client.config` 时注入 `Aurora.VerifyWebCredentials` 与对应环境。

## 6. 配置文件与工作目录

### 6.1 HsMod.cfg

主配置文件通常位于：

```text
Hearthstone/BepInEx/config/HsMod.cfg
```

如果使用 `hsunitid`，则位于：

```text
Hearthstone/BepInEx/config/<hsunitid>/HsMod.cfg
```

插件会在每次 `ConfigBind()` 时重新绑定当前语言下的配置分组与配置名称。语言变化后建议重启炉石，并备份旧配置。

### 6.2 HsSkins.cfg

皮肤映射配置通常位于：

```text
Hearthstone/BepInEx/config/HsSkins.cfg
```

格式：

```text
原始皮肤ID:替换皮肤ID
原始皮肤ID:替换皮肤ID1,替换皮肤ID2,替换皮肤ID3
```

示例：

```text
274:57761
```

含义是把原始皮肤 `274` 替换为 `57761`。多值映射会随机选择一个替换目标。

如果文件不存在，插件会根据语言资源自动生成默认模板。按 `F4` 会重新加载该文件。若在对局中修改英雄类皮肤，通常还需要模拟断线后才会看到效果。

### 6.3 BepInEx/HsMod 工作目录

插件会创建：

```text
Hearthstone/BepInEx/HsMod/
```

用途包括：

- Web 静态文件根目录。
- `match.log` 等插件日志。
- `mercenaries.log`、`skins.log`、`refundcards.log` 等导出信息。

## 7. Web 管理系统

Web 服务由 `WebServer.cs` 提供，默认端口来自配置项 `webServerPort`，默认值为 `58744`。

监听前缀：

```text
http://+:58744/
```

因此访问地址通常是：

```text
http://127.0.0.1:58744/
http://localhost:58744/
```

如果同一机器或局域网存在其他网络接口，`+` 前缀可能使服务可被其他地址访问。请谨慎配置防火墙。

### 7.1 页面路由

| 路由 | 说明 |
| --- | --- |
| `/`、`/home` | 首页。 |
| `/info` | 进程、账号资源、战令、天梯、任务等主要信息。 |
| `/pack` | 卡包已开数量与剩余数量。 |
| `/collection` | 收藏卡牌统计。 |
| `/skins` | 幸运币、卡背、棋盘、酒馆外观、英雄等 ID 信息。访问时也会导出 `skins.log`。 |
| `/lettuce` | 佣兵关卡信息。 |
| `/mercenaries` | 佣兵收藏与养成信息。 |
| `/matchlog` | 对局日志页面，依赖 `hsMatchLogPath`。 |
| `/alive` | 存活检查，返回进程 PID 与登录状态。 |
| `/bepinex.log` | 完整 BepInEx 日志。 |
| `/bepinex.min.log` | 最近 666 行 BepInEx 日志。 |
| `/hsmod.cfg` | 当前 HsMod 配置文本。 |
| `/hsskins.cfg` | 当前 HsSkins 配置文本。 |
| `/config` | Web 配置管理页面。 |
| `/about` | 关于页面。 |
| `/shell` | WebShell 页面。只有页面入口；命令执行仍受 `isWebshellEnable` 控制。 |
| `/jquery.min.js` | 嵌入的 jQuery 资源。 |

### 7.2 静态文件

除内置路由外，Web 服务会优先尝试从 `BepInEx/HsMod` 目录读取本地文件。路径校验要求目标文件必须位于该目录下，避免直接任意读取整个磁盘。

### 7.3 配置元数据 API

```http
GET /api/config?lang=zhCN
```

返回 JSON，大致结构：

```json
{
  "language": "zhCN",
  "groups": {
    "全局": [
      {
        "key": "isPluginEnable",
        "name": "HsMod状态",
        "label": "全局",
        "description": "是否启用插件（修改该选项后建议重启炉石）",
        "type": "bool",
        "value": "true",
        "isAdvanced": false
      }
    ]
  }
}
```

字段说明：

| 字段 | 说明 |
| --- | --- |
| `key` | C# 配置字段名，也是推荐给外部工具使用的稳定键。 |
| `name` | 当前语言下的配置显示名。 |
| `label` | 当前语言下的分组名。 |
| `description` | 配置说明。 |
| `type` | `bool`、`int`、`long`、`float`、`string`、`enum`、`keyboard`。 |
| `value` | 当前序列化值。 |
| `isAdvanced` | 是否高级项。当前仅 `pluginInitLanague`、`isEulaRead`、`isDynamicFpsEnable` 被标记，高级项判断仍较粗。 |
| `enumValues` | 枚举可选值，仅枚举项存在。 |
| `min`、`max` | 可接受范围，仅带 `AcceptableValueRange` 的配置存在。 |
| `keyCodes` | 键盘快捷键可用 KeyCode 名称，仅 `KeyboardShortcut` 存在。 |

### 7.4 修改配置 API

```http
POST /config
Content-Type: application/json

{
  "key": "timeGear.name",
  "value": "4"
}
```

推荐桌面工具直接使用稳定字段名并追加 `.name`：

```json
{
  "key": "isTimeGearEnable.name",
  "value": "true"
}
```

服务端处理逻辑：

1. 如果 `key` 已以 `.name` 结尾，则直接使用。
2. 否则尝试把本地化显示名反查成语言键。
3. 去掉 `.name`，通过反射查找 `PluginConfig` 的同名静态字段。
4. 使用 BepInEx `TomlTypeConverter` 写入序列化值。
5. 返回：

```json
{
  "status": 200,
  "output": "true"
}
```

限制：

- 当前接口禁止修改 `isWebshellEnable`，返回 `403`。
- 当前接口一次只改一个配置。
- 当前响应 JSON 是手工拼接，若输出内容包含特殊字符，理论上存在转义不完整风险，后续应改为 `JsonConvert.SerializeObject`。
- 不是所有配置写入后都能立即完全生效，见“实时生效规则”。

### 7.5 更新 HsSkins.cfg

```http
POST /update
Content-Type: application/json

{
  "key": "hsskins.cfg",
  "value": "274:57761\n"
}
```

支持的 `key`：

- `hsskins.cfg`
- `hsskins`

成功后会写入 `BepInEx/config/HsSkins.cfg` 并调用 `LoadSkinsConfigFromFile()`。

### 7.6 WebShell

```http
POST /webshell
Content-Type: application/json

{
  "command": "dir"
}
```

只有 `isWebshellEnable=true` 时才执行。Windows 下使用 `cmd.exe /C chcp 65001 & <command>`，macOS/Linux 下使用 `/bin/sh -c`。命令最长等待 5 秒，超时会尝试杀死进程并返回空字符串。

强烈建议：

- 默认保持关闭。
- 不要暴露 Web 端口到公网。
- 后续桌面工具不依赖 WebShell。

## 8. Patch 管理与实时生效规则

`PatchManager.PatchAll()` 会加载一组基础 Patch：

```text
Patcher
Patcher.PatchAntiCheat
Patcher.PatchMisc
Patcher.PatchEmote
Patcher.PatchIGMMessage
Patcher.PatchMercenaries
Patcher.PatchHearthstone
Patcher.PatchLogArchive
Patcher.PatchBattlegrounds
Patcher.PatchBgsUnlockCollection
Patcher.PatchFavorite
Patcher.PatchFakeDevice
Patcher.PatchDevOptioins
```

以下 Patch 会按配置动态加载或卸载：

| 配置项 | Patch 类 | 说明 |
| --- | --- | --- |
| `isShowCardLargeCount` | `PatchRealtimeCardNum` | 收藏卡牌数量显示。 |
| `isBypassDeckShareCodeCheckEnable` | `PatchDeckShareCode` | 卡组分享代码检测绕过。 |
| `isMoveEnemyCardsEnable` | `PatchDeathOb` | 观战手牌显示。 |
| `isAutoRecvMercenaryRewardEnable` | `PatchMercenariesReward` | 佣兵奖励弹窗/宝箱处理。 |
| `isAutoOpenBoxesRewardEnable` | `PatchBoxesReward` | 自动打开结算盒。 |
| `isFakeOpenEnable` | `PatchFakePackOpening` | 模拟开包。 |
| `isKarazhanFixEnable` | `PatchKarazhan` | 卡拉赞修复/跳关相关。 |

配置实时性可分为四类：

| 类型 | 配置或行为 | 生效方式 |
| --- | --- | --- |
| 立即更新内存值 | 多数 bool、int、enum 配置 | Patch 代码每次读取 `ConfigEntry.Value`，修改后立即影响后续逻辑。 |
| 有 SettingChanged 委托 | `isPluginEnable`、`isTimeGearEnable`、`timeGear`、`targetFrameRate`、`isIdleKickEnable`、动态 Patch 项、`skinCardBack`、`buyAdventure`、`configTemplate` | 写入配置后自动执行附加逻辑。 |
| 需要游戏状态配合 | 皮肤、英雄、宠物、棋盘、对局内外观 | 可能需要 `F4`、进入新场景、模拟断线或重启炉石。 |
| 启动读取或命令行覆盖 | `webServerPort`、`fakeDevicePreset`、内部模式、语言、部分 Patch 初始化项 | 通常需要重启炉石。 |

特别说明：

- `webServerPort` 在 `ConfigBind()` 后复制到 `CommandConfig.webServerPort`，Web 修改配置本身不会同步更新运行中的监听端口。需要重启炉石，或未来为该项增加专门的端口重启接口。
- `isWebshellEnable` 不能通过当前 `/config` 接口开启。
- `isAutoRefundCardDisenchantEnable` 在每次启动后会被强制设为 `false`，使用前必须手动开启。
- `F4` 可以重新加载皮肤配置并重启 Web 服务，但不等于所有配置都重新绑定。

## 9. 配置项速查

以下配置名来自 `Languages/zhCN.json`，字段名来自 `PluginConfig.cs`。默认值以源码绑定值为准。

### 9.1 全局

| 字段 | 中文名 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `isPluginEnable` | HsMod状态 | `true` | 插件总开关，关闭会卸载已加载 Patch。 |
| `pluginLanague` | HsMod语言 | 当前系统语言 | 修改后建议重启，旧配置名可能变化。 |
| `configTemplate` | 设置模板 | `DoNothing` | 应用挂机/反挂机模板，应用后自动回到 `DoNothing`。 |
| `isShortcutsEnable` | 快捷键状态 | `false` | 总快捷键开关。 |

## 10. 配置模板

`configTemplate` 有三个枚举值：

| 值 | 说明 |
| --- | --- |
| `DoNothing` | 默认，不修改配置。 |
| `AwayFromKeyboard` | 挂机模板。 |
| `AntiAwayFromKeyboard` | 反挂机模板。 |

`AwayFromKeyboard` 会设置：

- 关闭快捷键。
- 隐藏游戏内消息与弹窗。
- 弹窗响应设为 `YES`。
- 取消应用焦点要求。
- 关闭奖励提示。
- 开启自动开结算盒与报错退出。
- 禁用长时间无操作检测。
- 开启快速开包。
- 开启佣兵自动领奖。
- 关闭佣兵缩放。
- 跳过英雄介绍。
- 禁用思考表情，表情接收限制设为 `0`。
- 关闭对手金卡特效。
- 幸运币设为 `1746`。
- 禁用佣兵钻石/随机皮肤、金卡特效、最高特效。

`AntiAwayFromKeyboard` 会设置：

- 开启快捷键。
- 显示游戏内消息与弹窗。
- 弹窗响应设为 `DONOTHING`。
- 取消应用焦点要求。
- 显示奖励提示。
- 关闭自动开结算盒与报错退出。
- 开启长时间无操作检测。
- 开启快速开包。
- 开启佣兵自动领奖。
- 关闭佣兵缩放。
- 跳过英雄介绍。
- 禁用思考表情，表情接收限制设为 `3`。
- 开启对手金卡特效。
- 幸运币恢复 `-1`。
- 关闭默认英雄强制替换。
- 相关卡牌/佣兵特效恢复 `Default`。

模板应用完成后会自动把 `configTemplate` 设回 `DoNothing`。

## 11. Windows 桌面管理工具计划

### 11.1 目标

计划开发一个 Windows 桌面管理工具，用来实时调整 HsMod 插件参数，并提供比当前 Web 页面更稳定、更适合长期使用的管理体验。

本次不实现，只列计划。

核心目标：

- 自动发现或手动连接正在运行的 HsMod Web 服务。
- 展示插件状态、炉石进程 PID、登录状态、版本、运行端口。
- 读取 `/api/config` 元数据，自动生成桌面配置界面。
- 调整配置并通过 `/config` 实时写入。
- 编辑并更新 `HsSkins.cfg`。
- 查看 BepInEx 日志、对局日志、皮肤信息、佣兵/卡包/收藏信息。
- 管理常用预设，例如挂机、反挂机、开包、皮肤配置、低风险日常配置。
- 明确提示哪些配置能实时生效，哪些需要 F4、模拟断线或重启炉石。

### 11.2 推荐技术路线

推荐方案：

- 桌面框架：WPF + .NET 8，或 WinUI 3 + Windows App SDK。
- 架构：MVVM。
- HTTP 通信：`HttpClient`。
- 配置模型：基于 `/api/config` 动态生成，不在桌面端硬编码全部字段。
- 本地存储：JSON 配置文件保存最近连接、常用端口、预设、窗口状态。
- 打包：单文件或 MSIX；若后期公开分发，考虑代码签名。

如果未来考虑跨平台，可以改用 Avalonia，但当前需求是 Windows 桌面管理工具，WPF/WinUI 的开发效率更高。

### 11.3 当前接口复用方式

第一版桌面工具可以直接复用当前 HTTP 接口：

1. 用户输入或工具扫描端口，访问：

```http
GET http://127.0.0.1:58744/alive
```

2. 读取配置元数据：

```http
GET http://127.0.0.1:58744/api/config?lang=zhCN
```

3. 修改配置：

```http
POST http://127.0.0.1:58744/config
Content-Type: application/json

{
  "key": "timeGear.name",
  "value": "4"
}
```

4. 更新皮肤映射：

```http
POST http://127.0.0.1:58744/update
Content-Type: application/json

{
  "key": "hsskins.cfg",
  "value": "274:57761\n"
}
```

5. 查看日志和页面数据：

```http
GET /bepinex.min.log
GET /matchlog
GET /hsskins.cfg
GET /hsmod.cfg
GET /pack
GET /skins
GET /mercenaries
```

第一版不要依赖 `/webshell`。

### 11.4 建议先增强插件 API

为了让桌面工具更可靠，建议在开发桌面端前先给插件补充几个小型 JSON API。下面只是计划，不在本次实现。

#### 11.4.1 状态接口

```http
GET /api/status
```

建议返回：

```json
{
  "plugin": {
    "guid": "HsMod",
    "version": "11.3.0.2",
    "enabled": true,
    "language": "zhCN",
    "runningTime": 1234
  },
  "game": {
    "pid": 12345,
    "login": true,
    "mode": "GAMEPLAY",
    "hsunitid": ""
  },
  "web": {
    "port": 58744,
    "prefix": "http://+:58744/"
  },
  "patches": [
    "Patcher",
    "PatchMisc",
    "PatchHearthstone"
  ]
}
```

价值：

- 桌面端无需解析 HTML。
- 能显示 Patch 当前状态。
- 能支持多开区分。

#### 11.4.2 批量配置接口

```http
POST /api/config/batch
```

建议请求：

```json
{
  "items": [
    { "key": "isTimeGearEnable", "value": "true" },
    { "key": "timeGear", "value": "4" }
  ]
}
```

价值：

- 应用预设时避免连续请求。
- 可以统一返回每个配置的成功/失败。

#### 11.4.3 动作接口

```http
POST /api/action
```

可支持动作：

| action | 说明 |
| --- | --- |
| `reloadSkins` | 等价于重新加载 `HsSkins.cfg`。 |
| `restartWeb` | 重启 Web 服务。 |
| `simulateDisconnect` | 模拟断线。 |
| `showFpsToggle` | 切换 FPS。 |
| `readNewCards` | 清除新卡标记。 |
| `reloadLanguage` | 重新读取语言资源。 |

价值：

- 桌面端不需要模拟按键。
- 皮肤修改后的“应用”流程更清楚。

#### 11.4.4 配置元数据增强

建议 `/api/config` 为每个配置项增加：

| 字段 | 说明 |
| --- | --- |
| `effect` | `instant`、`patchReload`、`sceneReload`、`disconnect`、`restart`。 |
| `risk` | `normal`、`experimental`、`dangerous`。 |
| `readonly` | 当前状态下是否只读。 |
| `source` | `config`、`commandLine`、`runtime`。 |
| `categoryOrder` | 分组排序。 |

价值：

- 桌面工具能准确提示“立即生效/需要重启/慎用”。
- 避免把危险项做成普通开关。

#### 11.4.5 安全增强

建议增加：

- 可配置监听地址，默认绑定 `127.0.0.1`，而不是 `+`。
- 本地随机 token，保存在 `BepInEx/config/HsMod.api.key`。
- 所有 `/api/*` 写操作要求 `Authorization: Bearer <token>`。
- WebShell 独立强警告，不纳入普通桌面工具。
- 所有 JSON 响应统一由 JSON 序列化库输出，避免字符串转义问题。

### 11.5 桌面工具功能模块

#### 11.5.1 连接管理

功能：

- 默认尝试连接 `127.0.0.1:58744`。
- 支持手动填写 Host 与 Port。
- 支持扫描常见端口，例如 `58744`、用户历史端口、命令行指定端口。
- 显示连接状态、PID、登录状态、插件版本。
- 支持多实例列表：通过不同端口或未来的 `hsunitid` 区分。

#### 11.5.2 仪表盘

显示：

- 插件启用状态。
- 当前炉石进程 PID。
- 登录状态。
- 运行时间。
- 当前 Patch 数量和列表。
- 当前 Web 端口。
- 关键快捷开关：插件状态、齿轮状态、齿轮倍率、FPS、快捷键状态、快速开包、快速战斗。

#### 11.5.3 配置管理

基于 `/api/config` 动态生成控件：

| 类型 | 控件 |
| --- | --- |
| `bool` | 开关 Toggle。 |
| `int`、`long`、`float` | 数字输入框与滑条，尊重 `min/max`。 |
| `string` | 文本框。 |
| `enum` | 下拉框。 |
| `keyboard` | 快捷键录制框。 |

需要支持：

- 搜索配置项。
- 按分组展示。
- 显示高级/危险项确认。
- 显示默认值、当前值、修改状态。
- 修改后立即 POST `/config`。
- 保存失败时回滚 UI。
- 对需要重启的项显示提示。

#### 11.5.4 预设管理

内置预设：

- 原版保守：仅开启信息展示与低风险优化。
- 挂机：对应 `AwayFromKeyboard`。
- 反挂机：对应 `AntiAwayFromKeyboard`。
- 开包：开启快速开包、必要时提示自动开包风险。
- 皮肤预览：开启外观相关设置，但提示哪些需要 F4/断线/重启。
- 低资源：限制帧率、关闭高消耗显示。

用户预设：

- 保存当前配置快照。
- 只保存变更项。
- 支持导入/导出 JSON。
- 应用预设前展示差异。

#### 11.5.5 皮肤管理

功能：

- 读取 `/hsskins.cfg`。
- 提供表格编辑：原始 ID、替换 ID、随机候选。
- 支持校验格式。
- 支持一键写入 `/update`。
- 修改后提示执行 `reloadSkins` 或按 F4。
- 读取 `/skins` 或未来 JSON 接口，展示幸运币、卡背、棋盘、酒馆外观、英雄、宠物 ID。
- 支持收藏常用皮肤 ID。

#### 11.5.6 日志与诊断

功能：

- 查看 `/bepinex.min.log` 与 `/bepinex.log`。
- 查看 `/matchlog` 或未来 JSON 对局日志。
- 按错误、警告、Patch 关键字过滤。
- 一键复制诊断信息：
  - 插件版本。
  - 炉石 PID。
  - 端口。
  - 当前配置摘要。
  - 最近错误日志。

#### 11.5.7 数据页面

可以逐步替代当前 HTML 页面：

- 卡包信息。
- 收藏统计。
- 佣兵养成进度。
- 任务与战令信息。
- 天梯信息。
- 对局记录。

第一阶段可以直接嵌入 WebView2 显示现有页面；后续再通过 JSON API 原生化。

### 11.6 实时调整策略

桌面工具应把“实时”拆成可解释的几类：

| 生效等级 | UI 提示 | 示例 |
| --- | --- | --- |
| 立即生效 | 保存后立即生效 | `timeGear`、`isTimeGearEnable`、`targetFrameRate`。 |
| Patch 重载 | 保存后动态加载/卸载补丁 | `isShowCardLargeCount`、`isFakeOpenEnable`。 |
| 场景刷新 | 进入新界面或新对局后生效 | 部分外观、收藏显示。 |
| 需要断线 | 需要模拟断线重连 | 英雄皮肤、部分对局内外观。 |
| 需要重启 | 重启炉石后生效 | 语言、内部模式、Web 端口、设备模拟。 |

第一版桌面工具可以维护一份本地规则表；更好的方案是在 `/api/config` 中由插件直接返回 `effect` 字段。

### 11.7 UI 草案

建议主界面：

```text
┌────────────────────────────────────────────────────┐
│ HsMod Manager    已连接 127.0.0.1:58744    PID ... │
├───────────────┬────────────────────────────────────┤
│ 仪表盘         │ 插件状态 / 登录状态 / 运行时间       │
│ 配置           │ 常用开关与当前 Patch 状态            │
│ 预设           │                                    │
│ 皮肤           │                                    │
│ 日志           │                                    │
│ 对局           │                                    │
│ 设置           │                                    │
└───────────────┴────────────────────────────────────┘
```

交互原则：

- 普通项默认可见，高级/危险项需要确认后显示。
- 每次修改给出明确反馈：成功、失败、需重启、需 F4、需断线。
- 对 `自动举报`、`零元购`、`冒险购买`、`WebShell` 等高风险功能使用单独风险确认。
- 不在桌面工具中默认暴露 WebShell。

### 11.8 开发里程碑

#### 阶段 0：接口梳理

- 固化当前 `/alive`、`/api/config`、`/config`、`/update` 行为。
- 标注每个配置项的生效等级。
- 决定是否先实现 `/api/status` 与批量配置接口。

#### 阶段 1：最小可用原型

#### 阶段 2：配置体验完善

- 高级项确认。

#### 阶段 3：皮肤与日志

### 11.9 风险清单

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| Web 服务默认监听所有网卡 | 可能暴露管理接口 | 桌面工具警告；插件后续增加本地绑定与 token。 |
| 当前 `/config` 只能单项写入 | 应用预设效率低且易部分失败 | 增加批量接口，或桌面端逐项写入并展示结果。 |
| 配置是否实时生效不统一 | 用户以为已生效但实际需要重启 | 增加生效等级提示。 |
| 本地化显示名可能变化 | 桌面工具找不到配置 | 外部工具始终使用 `key` 字段，不使用显示名作为主键。 |
| HTML 页面不适合结构化读取 | 桌面端难以稳定展示数据 | 后续增加 JSON 数据接口，第一版可用 WebView2 过渡。 |
| 多实例端口和配置目录混乱 | 连接错实例 | 状态接口返回 `hsunitid`、配置路径、PID。 |
| WebShell 风险极高 | 本机命令执行风险 | 桌面工具不集成 WebShell；插件侧保持默认关闭。 |
| 炉石更新导致 Patch 失败 | 插件崩溃或退出 | 桌面工具显示版本与最近 Patch 错误，辅助排查。 |

### 11.10 推荐的第一版范围

第一版只做这些：

- 连接管理。
- 仪表盘。
- 配置动态编辑。
- 预设导入/导出。
- `HsSkins.cfg` 编辑。
- 日志查看。
- 明确的生效提示。

第一版暂不做：

- WebShell。
- 自动注入或启动炉石。
- 复杂账号管理。
- 修改 BepInEx 安装结构。
- 远程公网管理。

这样可以最大程度复用当前插件已有 Web API，避免桌面工具一开始就和游戏进程耦合过深。

## 12. 后续维护建议

1. 把配置项的“生效等级”和“风险等级”补进源码元数据，供 Web 与桌面端共用。
2. 把 `/config` 与 `/update` 的响应改成真正 JSON 序列化。
3. 增加 `/api/status`、`/api/config/batch`、`/api/action`。
4. 增加本地 token 与监听地址配置，默认只监听 `127.0.0.1`。
5. 把现有 HTML 信息页逐步拆成 JSON API，桌面端和 Web 端都能复用。
6. 将 README、中文文档与 Web 配置描述保持同步，避免配置项新增后文档滞后。
